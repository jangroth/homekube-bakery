# Semver tags with a CI-computed patch

Bakery images are tagged with semver as plain `MAJOR.MINOR.PATCH` (no `v`), versioned independently per image, and tags are immutable: no `latest` or other floating tags are published. Levels follow the contract, not upstream versions: major means a contract break a consumer may need to react to, minor means the contract gains something (a new tool or toolchain), and patch means anything that keeps the contract, including rebuilds and tool upgrades of any level. Each image's `VERSION` file holds `MAJOR.MINOR` and is bumped by a human; CI assigns the next free patch from the tags already in GHCR, so scheduled rebuilds publish without a commit. We chose this over `YYYYMMDD.N` because it states consumer impact, and over release-please because that works through release PRs.
